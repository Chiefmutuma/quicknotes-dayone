About QuickNotes

QuickNotes is a simple web app for jotting down ideas, reminders, and to-do items. It is designed for quick capture, so you can write a note in seconds without creating an account or learning complicated tools.

How to use QuickNotes

  1. Open the Home page in your web browser.
  2. Type a title for your note in the "Note title" box.
  3. Write the details of your note in the large text box below it.
  4. Press the "Save Note" button to add the note to your list.

Features

  • Save notes with a title and body text
  • View all of your notes in one list
  • Delete notes you no longer need
  • Works in any modern web browser

Keyboard shortcuts

Shortcut Action
Ctrl + Enter Save the current note
Esc Clear the note form
Ctrl + Delete Delete the selected note
